## 项目目标

在墙面投影一个会呼吸、成长、对人的靠近和抚摸产生反应的生命体。最终体验是：用户面对墙面，用手和身体与墙上的碎光互动；碎光根据互动变化、成长并发光。

当前优先目标是完成实体硬件链路：

`Gemini 335 深度相机 → Mac → 距离/近墙区域算法 → 投影网站 → 墙面互动`

网页远程试玩和实体投影是两种模式：远程试玩可以使用浏览器摄像头或鼠标；实体模式不应要求用户打开网页摄像头，深度相机由本地 Mac 读取。

## 当前算法行为

1. 先对空墙做 30 帧校准，建立逐像素冻结背景。
2. 用墙面法向计算当前可见表面相对空墙的位移。
3. 近墙区域单独输出，持续约 150 ms 后才形成短时跟踪点。
4. 远离墙面的身体整体不会直接生成交互点。
5. 数据过期、背景大面积失配或无效深度会清除跟踪点。
6. 固定测量框使用所有有效像素，不经过“前景”“近墙”筛选，输出有符号的可见表面法向位移。

必须区分：

- 光轴深度不是相机到物体的欧氏距离。
- 可见表面离墙的位移不等于皮肤真实接触间隙。
- 近墙区域不等于识别出“手”。
- 当前没有人物身份识别，也没有人物数据库。
