# 墙面距离测量复盘与验证（Issue #25）

## 现有证据
2026-09-19 13:31 本机报告：空墙74次、离开73次均无近墙区域；移动阶段111次中67次输出稳定点；停留74次和身体干扰91次均输出点。报告没有物理距离真值，不能证明精度、真实接触、身体干扰下始终跟手，也不能把67/111称为识别准确率。

## 之前的错误
把空墙误报、手部跟踪与距离精度混成一次测试。用手估计2–3厘米没有真值。检测器的gap取筛选后区域20分位，无法用它独立验证筛选门限。停留时10–17毫米不必然是误差：相机看到手背/可见表面，而真正与墙接触的皮肤可能被遮住。表面离墙不等于接触间隙。

## 测量定义
读取深度单位与内参，把像素还原为三维位置；使用空墙参考和墙面法向，估计可见表面沿墙面法向相对参考的位移。原有冻结逐像素背景可减少固定墙面起伏误报，但结果仍是局部参考估算。camera_z_mm是光轴深度，不是相机到点的欧氏距离。

新增固定中心小框：使用所有有效参考像素，不经前景/正值/50毫米近墙筛选，报告有符号中位数、框内P10–P90范围、有效比例及相机光轴深度。负数和零保留，无效数据返回空值。空间分位范围不是时间抖动或精度。基线大范围失配时测量可显示但不能采纳为可信实测。

## 实物流程
1. 固定相机、墙面与测量框。保持当前约一米位置作为单次实验条件，不宣称最优距离。投影先关闭。
2. 空墙校准一次，随后空墙记录10秒，测零点、漂移与有效比例；不能每个距离重新归零。
3. 准备平整、哑光、不透明硬物，用尺实际量厚度。目标可约10/20/40毫米，但录入实测值，不能假定书本或盒子的厚度。前后面尽量平行、贴墙无缝、覆盖小框，手握边缘不能遮住小框。
4. 每个厚度摆放后明确开始，静止记录10秒，取走，再放回，独立重复3次；不同厚度之间回到空墙检查基线。不能用全程倒计时替代“物体已放好”的确认。
5. 每档报告实测厚度、测量中位数、带符号偏差、时间P5–P95、无效比例和重复摆放差异。相邻厚度的读数范围明显重叠则不能宣称可分辨该间距。
6. 中心可用后再把测量位置扩展到四角；先解决测距，再验证范围覆盖，最后开投影做同条件对照。
7. 手掌实验另立目标：物理贴墙与离墙各重复，记录可见表面值和跟踪位置。两状态若无法稳定区分，产品只能称“靠墙互动”，不能称触摸检测。之后再做移动/身体干扰与投影坐标对应。
